# How to win

- **Rubric:** 5 criteria × 1–5, equal weights (see [`HACKATHON.md`](../../HACKATHON.md)). Judges said out loud they care about **applicability and uniqueness**, and strongly recommend **Grok Bot** (and Cursor).
- **Skip the slide examples** (coding crew, research team, PR review, nightly cleanup) — half the room will build them.
- **Hit the demo scenarios from the speaker notes:** two agents talking to each other, a bot finishing a task and posting to Slack, a bot driving an app with no API.
- **Technical 5 needs** tools + real data + error handling. No mocks in the demo.
- **Impact 5 examples** in the rubric: accessibility, productivity gains.
- **Grok API alone** reads as "basic AI interaction" (2–3). Grok Bot group chats, computer use and skills reach 4–5.
- **Final pitch ≈ 1 minute.** Record the run and speed it up; bots take minutes live.
- **Submission:** private repo with judges invited, frequent commits, AI session exports in `/sessions`.
